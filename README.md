# 澜心社学员分享音频与转写文稿专用资料库

本仓库用于长期归档澜心社的学员分享、用户案例与音频转写资料，便于后续开展用户案例分析、学员反馈整理、痛点与金句提炼、产品效果总结、用户画像、短视频素材、课程反馈及品牌案例库建设。

## 目录说明

- `学员分享音频-转写文稿/`：桌面源目录的原始资料副本，保留原始中文文件名与内容。
- `可检索文本/`：供 AI 检索使用的纯文本层；本次全部源文件均为 `.txt`，因此按原目录结构完整复制。
- `资料索引.md`：文件统计、资料目录与待转写情况。

## 归档原则

- 桌面源文件未被删除、移动、改名或修改。
- 已排除 `.DS_Store`、`._*` 等系统文件。
- 本次资料中未发现音频、视频、PDF、Word、图片或超大文件，因此未启用 Git LFS。
