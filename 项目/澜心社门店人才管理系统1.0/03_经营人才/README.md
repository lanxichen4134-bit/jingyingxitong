## 核心原则

- 店长是门店CEO，对利润、客户、团队与合规共同负责。
- 经营晋升不等同于技术晋升。
- 先经营分红权，后真实股权。
- 股权对应真实投资、长期责任和经营结果，不作为普通激励随意发放。
- 新店复制收益来自实际开店与辅导工作，不形成层级抽佣。
