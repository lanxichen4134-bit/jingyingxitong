# 澜心社门店技术合伙人机制1.0

## 一、角色定位

技术合伙人是门店专业体系的第一责任人，可理解为门店的“技术CEO”。

技术合伙人不是通过招人形成层级收益的代理角色，也不是单纯对外使用的高级技师头衔，而是承担真实人才管理、专业质量和技术复制责任的经营角色。

门店三方共营结构：

- **平台/公司**：负责品牌、资金、会员、流量、产品、课程、供应链、系统、技术标准、财务与资源合伙人/投资合伙人招募；
- **经营合伙人/店长**：负责门店P&L、客户运营、团队协同、本地经营、成本与服务体验；
- **技术合伙人**：负责技术人才、专业交付、技术质量、培训复制与专家体系。

底层原则：

> 平台提供资源，经营合伙人把生意经营好，技术合伙人把专业与人才经营好。

---

## 二、准入原则

技术合伙人原则上从6星以上优秀技术人才中选拔，7星优先。

五星可以成为导师并开始带教，但不自动获得技术合伙人资格。

候选人至少应满足：

1. 专业技术达到高等级标准；
2. 有稳定客户满意度、复购与指定表现；
3. 已具备带教或培训经验；
4. 能够执行并维护澜心技术SOP；
5. 能处理复杂案例、技术纠偏与技术类客诉；
6. 能招募、识别、培养和留住技术人才；
7. 无重大私单、诚信、安全或合规记录；
8. 接受平台数据、客户与人才统一管理原则。

技术合伙人不是终身身份，应按经营周期复审。

---

## 三、核心职责

### 1. 技术人才招募

- 根据门店产能计划制定技术人才需求；
- 参与面试与专业能力评估；
- 建立本地技术人才储备池；
- 为新店复制提前储备技术骨干。

人才属于澜心平台人才体系，不属于某位导师或技术合伙人的私人团队。

### 2. 培养与晋升

- 负责1—4星基本功培养；
- 建立五星导师带教体系；
- 组织星级考核与晋升建议；
- 对低星级技师制定成长计划；
- 对高星级技师制定专家与进修计划。

最终星级认证按平台统一标准执行，避免单店自行降低标准。

### 3. 技术质量

- 执行项目SOP与技术标准；
- 建立案例复盘制度；
- 对复杂案例进行会诊与方案支持；
- 管理技术质量、卫生安全、服务边界；
- 负责重大技术类客诉的专业处理。

### 4. 排班与产能

技术合伙人参与专业维度排班与客户匹配：

- 不同项目由对应星级技师交付；
- 高难项目优先安排高级/专家技师；
- 控制专家被基础服务占满的低效使用；
- 建立老带新的合理排班结构；
- 保障门店技术产能与新人成长兼顾。

### 5. 技术复制

- 为新门店输出成熟技师；
- 带领5星以上导师复制新人；
- 参与新店开业技术团队搭建；
- 将优秀案例、方法和改进沉淀为平台标准。

---

## 四、技术合伙人的收益结构

收益必须对应真实贡献，不形成“发展下线”的层级计酬。

可包含：

1. **本人技术交付收入**：按本人星级享受操作费收益；
2. **客户指定费**：客户主动指定产生的指定服务费100%归本人；
3. **专家项目收入**：承担高级/专家项目获得对应专家收入；
4. **培训授课费**：承担正式课程、实操培训获得培训收入；
5. **带教费/培养质量奖**：对实际承担的新人培养与认证结果获得收益；
6. **技术管理奖**：基于所管理技术团队的质量、成长、稳定与客户结果获得；
7. **门店合伙收益**：达到经营合伙条件后，可进入门店经营分红或真实股权机制。

明确禁止：

- 因“某人是我招来的”永久抽取其个人业绩；
- 因“我的徒弟又招了徒弟”形成多层级收益；
- 按团队人数简单决定技术管理奖；
- 用缴费购买技术合伙人身份。

---

## 五、技术管理奖建议考核维度

技术管理奖不直接与“发展人数”挂钩，而与技术团队的真实经营结果挂钩。

建议1.0使用以下指标：

| 维度 | 建议权重 | 观察内容 |
|---|---:|---|
| 客户满意与技术质量 | 25% | 满意度、客诉、技术安全 |
| 人才合格率与晋级率 | 20% | 培训后真实能力成长 |
| 技师留存与团队稳定 | 15% | 核心人才留存、非正常流失 |
| 技术SOP执行 | 15% | 服务标准、案例档案、质检 |
| 客户指定与复购 | 10% | 专业认可，而非强销售 |
| 培训与案例复盘 | 10% | 培训完成率、案例沉淀 |
| 新店/跨店支持 | 5% | 实际完成的人才与专业支持 |

重大安全、私单、数据造假、严重违规实行一票否决或暂停技术管理资格。

## 六、四条人才发展路径

### 路径A：专业技术线

实习/学员 → 1星 → 2星 → 3星 → 4星 → 5星高级技师 → 6星专家 → 7星首席专家。

目标：允许真正热爱技术的人不做管理，也能获得高收入、高身份、高自由度。

### 路径B：技术管理线

5星导师 → 6星技术负责人候选 → 技术合伙人 → 区域技术合伙人 → 技术委员会成员。

目标：把“自己会做”升级为“能够培养一支专业团队”。

### 路径C：经营管理线

优秀员工 → 储备店长 → 店长 → 区域经营负责人。

目标：培养对门店经营结果和P&L负责的人才。

### 路径D：门店合伙线

经营骨干/技术骨干 → 经营合伙人或技术合伙人 → 门店股东 → 多店/区域合伙人。

门店股权是长期投资与经营责任，不因星级或职位自动获得。

## 七、技术人才薪酬机制原则

技术人才薪酬应与星级同步升级，逐渐从“保障收入”转向“专业价值定价”。

收入模块可由以下部分组成：

> 基础保障 + 星级操作收入 + 会员/续费收益 + 客户指定费 + 培训/带教收入 + 专家项目收入 + 技术管理奖 + 合伙收益

不同星级启用不同模块：

- 1—2星：重点保障与培养；
- 3—4星：增加操作收益与排班自由；
- 5星：完整技术交付收益并开放导师收入；
- 6星：增加专家项目、跨店技术支持和技术管理候选资格；
- 7星：增加专家指定、研发、全国巡回和技术合伙资格。

具体固定薪酬、星级系数、单项金额必须结合门店真实项目毛利和当地用工成本另行制定，不在总纲中拍死。

---

## 八、权责边界

### 平台拥有

品牌、会员、客户数据、技术认证体系、项目标准、课程、产品供应链、结算系统和全国资源。

### 门店经营团队拥有

本店经营管理权限，并对收入、成本、客户运营和利润负责。

### 技术合伙人拥有

技术管理授权、人才培养责任和与专业贡献对应的收益，但不拥有客户或技师的私人归属权。

原则：

> 客户可以指定某位老师，但客户资产属于平台；技师可以由某位导师培养，但人才属于平台人才体系；技术合伙人的收益跟随当前真实管理责任，而不是跟随历史招募关系。

---

## 九、1.0试运行建议

首店先选1名技术合伙人候选人，试运行90天。

重点验证：

1. 技术团队是否更稳定；
2. 低星级技师成长是否加快；
3. 技师对星级和收入机制是否有动力；
4. 客户满意度和指定率是否提高；
5. 私单与师徒山头风险是否降低；
6. 技术合伙人的管理工作量与收益是否匹配；
7. 技术管理奖能否在门店毛利范围内长期成立。

90天后再确定技术管理奖具体金额/比例，并升级到1.1。
