# 澜心社门店人才管理系统1.0

## 项目定位

本项目用于沉淀澜心社门店的人才培养、晋升、考核、激励、技术等级、技术合伙、经营晋升与门店合伙机制。

它不是传统“员工薪酬制度”，而是澜心社门店平台化经营的人才操作系统。

## 核心目标

1. 让技术人才通过专业能力持续提升收入、身份与时间自主权；
2. 让优秀技术人才通过带教、培训和技术复制突破个人产能上限；
3. 建立“专业技术线 + 技术管理线 + 经营管理线 + 门店合伙线”四条发展路径；
4. 让高等级技术人才有机会成为门店技术合伙人，负责人才招募、培养、定级、技术质量与专业交付体系；
5. 培养储备店长、店长、经营合伙人与未来门店股东；
6. 建立“平台负责资源与资本、门店负责经营管理、技术体系负责专业交付”的三方共营机制；
7. 为未来门店复制与全国会员服务网络建立可复制的人才底盘。

## 已确认的核心经营规则

### 三账分配

- 会员费：平台40%｜门店30%｜技术侧30%
- 会员操作费：平台30%｜门店30%｜技术交付池40%
- 升单/续费：平台40%｜门店30%｜技术侧30%
- 客户主动指定高级/专家技师产生的指定服务费：100%归被指定技师

内部记忆口令：

> 会员433，操作334，续费433，指定费老师100%。

### 人才成长原则

> 低等级靠纪律成长，中等级靠能力获得自由，高等级靠结果获得自由，顶级人才靠创造更大的组织价值获得更大的事业空间。

### 平台共营原则

> 资本获得资本收益，经营获得经营收益，技术获得技术收益；谁创造价值，谁获得对应回报。

## 四条人才发展路径

1. **专业技术线**：实习/学员 → 1星 → 2星 → 3星 → 4星 → 5星高级技师 → 6星专家 → 7星首席专家。
2. **技术管理线**：5星导师 → 6星技术负责人候选 → 7星/成熟6星技术合伙人 → 区域技术合伙人/技术委员会。
3. **经营管理线**：优秀员工 → 储备店长 → 店长 → 区域经营负责人。
4. **门店合伙线**：经营骨干/技术骨干 → 经营合伙人或技术合伙人 → 门店股东 → 多店/区域合伙人。

## 技术合伙人定位

技术合伙人是门店的“技术CEO”，不是简单的高级技师头衔。

核心职责：

- 技术人才招募与人才池建设；
- 1—7星技师培养、考核与定级建议；
- 五星以上导师体系建设；
- 技术SOP、质量管理与案例督导；
- 技师排班与产能配置建议；
- 客户专业交付质量、满意度与重大技术客诉负责；
- 新店技术团队搭建与人才复制。

原则上从6星以上优秀人才中选拔，7星优先；必须同时满足专业、带教、管理、客户评价和合规要求。

技术合伙人可以获得专家项目收入、培训费、带教费、技术管理奖及符合条件后的门店合伙收益，但不因“招了谁、谁是谁的徒弟”形成永久上下级抽佣。
