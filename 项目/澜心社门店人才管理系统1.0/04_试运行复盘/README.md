# 04｜试运行复盘

本目录用于记录《澜心社门店人才管理系统1.0》在首店90天试运行中的真实数据、问题与制度迭代。

## 重点观察指标

- 各星级技师人数结构
- 技师人均收入变化
- 客户满意度
- 客户指定率
- 会员项目使用率
- 五星以上带教参与率
- 新人晋级速度
- 技师流失率
- 私单/违规情况
- 门店人效
- 门店经营毛利
- 排班与产能利用率

## 复盘节奏

- 每周：运营问题记录
- 每月：人才与经营数据复盘
- 第90天：V1.0总复盘
- 输出：`澜心社门店人才管理系统V1.1`

## 核心原则

制度不是一次设计完成，而是通过真实经营数据不断校准。任何调整必须同时考虑客户价值、人才动力、门店利润和平台长期可复制性。
