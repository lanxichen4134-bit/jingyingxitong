# 澜心社门店人才管理系统1.0｜聊天讨论整理

> 时间范围：2026-08-31 至 2026-09-14
> 用途：沉淀本轮关于门店人才、技师晋升、薪酬分配、技术合伙人、门店共营与复制机制的核心讨论，作为1.0后续迭代依据。

## 一、门店组织定位

澜心未来门店不采用传统“公司雇员工完成服务”的单一雇佣逻辑，而建设为三方共营的平台型门店：

- **平台/公司**：负责品牌、IP、资金、资源、会员、流量、产品、课程、供应链、技术标准、培训认证、系统、财务和全国资源；同时负责招募资源合伙人和投资合伙人。
- **门店**：作为独立经营单元，负责空间、排班、本地客户体验、社群、运营、成本与利润结果。
- **技术人才**：负责专业评估、方案、技术交付、客户效果、案例沉淀；高级技术人才进一步承担带教、培训、技术复制和质量管理。

底层原则：

> 资本获得资本收益，经营获得经营收益，技术获得技术收益；谁创造价值，谁获得对应回报。

## 二、已确认的三账分配机制

### 1. 会员费

平台40%｜门店30%｜技术侧30%

目的：让公司、门店、技术端共同维护会员，不让会员只成为总部资产，也不让门店和老师觉得卖完卡以后只是承担履约。

### 2. 会员每次项目操作费

平台30%｜门店30%｜技术交付池40%

其中平台30%主要用于覆盖产品、耗材、包装、物流、品控和售后等标准成本，原则上不把单次操作费作为主要利润来源。

采用标准成本制，不逐单核算复杂成本；每个项目预设标准会员操作费和标准产品/耗材成本。

### 3. 客户升单/续费

平台40%｜门店30%｜技术侧30%

目的：客户持续消费由平台、门店、老师共同经营，共同分享长期价值。

### 4. 指定服务费

客户主动指定高级/专家技师产生的指定服务费，**100%归被指定技师本人**。

- 5—6星可设置低压力的高级技师指定费；
- 7星专家可设置更高但仍易接受的专家指定费；
- 若门店因排班原因主动安排高级技师，不额外强制收费。

内部记忆：

> 会员433，操作334，续费433，指定费老师100%。

## 三、七星技师体系

### 1星｜入门技师

完成新人培训，能按SOP完成基础项目，固定排班，重点是纪律、基本功和服务规范。

### 2星｜稳定技师

能够稳定完成基础项目交付，客户满意度和档案流程稳定。

### 3星｜独立技师

能够独立评估、给出基础方案，开始获得约2小时上下班弹性。

### 4星｜资深技师

能够处理更复杂客户，客户复购和指定增加，可进入储备管理训练。

### 5星｜高级技师 / 导师

通过导师认证，可以正式带新人、培训和带教；原则上完整获得技术交付池40%，并开始获得更高排班自主权。

### 6星｜专家技师 / 技术管理

能够处理疑难问题、进行跨店技术支持与督导，可进入技术管理与技术合伙人候选。

### 7星｜首席专家

代表澜心技术高度，承担专家服务、培训、研发、技术标准制定和全国巡回支持；持续进修、年度复审，采用专家预约和任务责任制，不以日常坐班为核心。

## 四、星级不是单纯薪酬等级，而是五种权益同步升级

1. **收入升级**：操作费比例、指定费、专家项目、带教和培训收入逐步增加。
2. **时间升级**：固定排班 → 弹性排班 → 预约/核心工作制 → 专家责任制。
3. **身份升级**：标准技师 → 高级技师 → 导师 → 专家 → 首席专家。
4. **资源升级**：获得更多VIP客户、专家客户、跨店与全国客户机会。
5. **事业升级**：技师 → 导师/技术负责人 → 技术合伙人，或进入储备店长 → 店长 → 门店股东。

核心原则：

> 低等级靠纪律成长，中等级靠能力获得自由，高等级靠结果获得自由，顶级人才靠创造更大的组织价值获得更大的事业空间。

## 五、星级与排班方向

- 1—2星：固定排班、正常考勤；人员充足时可以两班制，提高案例密度和学习效率。
- 3—4星：可根据预约和任务前后调整约2小时，逐步从考勤管理转向结果管理。
- 5—6星：预约 + 核心工作时段 + 培训任务制，获得更稳定的休息和时间自主权。
- 7星：按客户预约、专家项目、培训、研发、进修安排工作，不要求日常坐班，但必须对专业结果、带教和年度专业成果负责。

高星级获得的是“时间安排自主权”，不是规避劳动关系或基本劳动制度。

## 六、七星技术收入思路

会员操作费中的40%定义为“技术交付池”。

1.0建议内部逐步释放：

- 1星：28%
- 2星：30%
- 3星：32%
- 4星：36%
- 5—7星：40%

1—4星未释放部分进入导师带教、培训、认证、质量管理等人才培养池，不作为公司普通利润。

五星以上新增：

- 指定服务费
- 专家项目收入
- 培训授课费
- 实操带教费
- 学员认证通过奖
- 培养质量奖
- 技术管理奖

不采用“徒弟以后每做一单，师傅永久抽成”的师徒层级分成。

## 七、人才晋升机制

### 月度考核

一个月一次，只看少数核心指标：

- 技术：40%
- 客户：30%
- 纪律合规：20%
- 学习成长：10%

五星以上再增加组织贡献观察。

### 季度晋升

每3个月进行一次晋升评选，综合最近3个月表现、实操能力和红线记录。

不按工龄自动晋升。

晋升逻辑简化为：

> 1星会做 → 2星稳定做 → 3星独立判断 → 4星处理复杂客户 → 5星能带人 → 6星能解决技术问题并管理质量 → 7星能代表技术高度并创造组织价值。

### 红线

出现私单、重大客诉、违规操作、数据造假等，不予晋升；重大专业安全或诚信问题可暂停相关技术权限。

## 八、技术合伙人机制

技术人才未来不仅是员工，也可成长为门店的技术合伙人。

技术合伙人定位为门店“技术CEO”，不是单纯高级技师头衔。

主要职责：

- 技术人才招募与人才池建设；
- 1—7星技师培养、考核和定级建议；
- 五星以上导师体系建设；
- 技术SOP、质量管理和案例督导；
- 技师排班与产能配置建议；
- 重大专业客诉与交付质量负责；
- 新店技术团队搭建与人才复制。

原则上从6星以上优秀人才中选拔，7星优先。

收益来源于真实的专家服务、培训、带教、技术管理和门店合伙贡献，不因“谁是我招来的、谁是谁的徒弟”形成永久上下级抽佣。

## 九、四条人才发展路径

1. **专业技术线**：实习/学员 → 1星 → 2星 → 3星 → 4星 → 5星高级技师 → 6星专家 → 7星首席专家。
2. **技术管理线**：5星导师 → 6星技术负责人候选 → 7星/成熟6星技术合伙人 → 区域技术合伙人/技术委员会。
3. **经营管理线**：优秀员工 → 储备店长 → 店长 → 区域经营负责人。
4. **门店合伙线**：经营骨干/技术骨干 → 经营合伙人或技术合伙人 → 门店股东 → 多店/区域合伙人。

不是所有技术好的人都必须转管理；纯技术路线也可以做到很高收入和高自由度。

## 十、门店复制与人才复制

未来开新店时，不希望每一家店从零招聘，而是通过人才池和老带新机制输出完整团队。

技术合伙人负责技术团队复制；店长/经营合伙人负责经营复制；总部负责品牌、会员、产品、课程、流量、资金与系统。

门店复制收益应绑定真实的开店项目和经营辅导责任，而不是永久从“自己发展出来的下级门店”抽成。

未来如果发展到品牌、技术、经营模式授权给独立主体使用，需要单独审查是否构成商业特许经营并按相应规则处理。

优先级5：用现有团队进行第一次模拟套级，跑90天后升级为V1.1。
