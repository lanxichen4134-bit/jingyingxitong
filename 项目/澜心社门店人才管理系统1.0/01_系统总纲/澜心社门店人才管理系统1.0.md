# 澜心社门店人才管理系统1.0

## 一、系统定位

澜心未来的门店，不定义为“公司雇员工服务客户”的传统门店，而定义为一个由三方共同创造价值、共同分享收益的女性健康服务平台。

### 公司负责资源和平台能力

品牌、IP、资金、流量、会员、产品、课程、供应链、技术标准、培训认证、系统、财务、全国资源，以及招募资源合伙人与投资合伙人。

### 门店负责经营

空间、客户体验、人员排班、本地运营、社群维护、成本控制、经营利润和团队管理。

### 技师负责专业交付

评估、技术、方案、服务、客户效果、专业教育；高级技师进一步承担带教、培训、技术复制和标准建设。

三方共同经营客户，但客户档案、会员权益、服务记录和数据统一沉淀在澜心平台。

底层原则：

> 资本获得资本收益，经营获得经营收益，技术获得技术收益；谁创造价值，谁获得对应回报。

---

## 二、人才系统五个核心目标

1. 让刚进入澜心的普通技师看得见长期职业未来，而不是几年后仍只靠双手做项目。
2. 让优秀技术人员不必离开平台单干，也能获得越来越高的收入、身份和时间自由。
3. 让真正优秀的人复制人才，把个人技术逐渐变成澜心组织能力。
4. 把优秀经营人才逐步培养为储备店长、店长、经营合伙人与门店股东。
5. 让会员、人才与门店形成增长飞轮：会员增加 → 技师收入增加 → 优秀技师成长为导师 → 培养新人 → 支撑新店 → 优秀店长成为合伙人 → 新店承接更多会员 → 平台继续扩大。

---

## 三、人才采用“双通道 + 合伙人通道”

### A. 专业技术通道

实习/学员 → 一星技师 → 二星技师 → 三星技师 → 四星技师 → 五星高级技师/导师 → 六星专家技师 → 七星首席专家。

一个人可以长期走技术路线，不强迫优秀技师转管理。七星专家可以拥有较高收入、个人专业品牌、全国客户、培训收入和高度时间自主权，而不需要管理一家门店。

### B. 经营管理通道

优秀员工 → 储备店长 → 店长 → 经营合伙人 → 门店股东 → 区域经营负责人。

管理晋升不以技术星级最高为唯一标准，而看经营能力。原则上四星以上优秀技师可以申请储备店长；非技术岗位优秀人才也可以通过经营能力评估进入管理通道。

### C. 技术复制通道

五星高级技师 → 带教导师 → 六星专家导师 → 七星平台专家 → 技术委员会成员。

五星是重要分水岭：五星以前主要证明“我能把客户服务好”；五星以后还必须证明“我能把别人培养好”。

## 四、七星技师体系

| 星级 | 内部定位 | 客户看到的身份 | 工作方式 | 核心权限 |
|---|---|---|---|---|
| 1星 | 初级独立技师 | 标准技师 | 固定排班 | 标准基础项目 |
| 2星 | 成熟基础技师 | 标准技师 | 固定排班 | 更多标准项目 |
| 3星 | 独立技师 | 标准技师 | 弹性排班 | 独立评估与方案 |
| 4星 | 资深技师 | 标准/资深技师 | 弹性+预约 | 复杂项目、VIP服务 |
| 5星 | 高级技师/导师 | 高级技师 | 预约+核心工作制 | 带教、培训、专家项目 |
| 6星 | 专家技师 | 高级/专家技师 | 高度弹性 | 跨店服务、培训、技术督导 |
| 7星 | 首席专家 | 专家技师 | 专家预约制 | 全国专家、研发、标准、培训 |

客户端不展示七套复杂价格，尽量只呈现三档：

- 标准技师：1—4星
- 高级技师：5—6星
- 专家技师：7星

内部有七级成长，客户端保持简单。

## 五、七星技师收入结构

技术人才未来拥有五种收入来源。

### 1. 技术交付收入

会员每次项目操作费按照：

> 平台30%｜门店30%｜技术交付池40%

第一阶段建议将技术交付池按星级逐步释放：

| 星级 | 技师本人获得操作费比例 | 技术人才培养池 |
|---|---:|---:|
| 1星 | 28% | 12% |
| 2星 | 30% | 10% |
| 3星 | 32% | 8% |
| 4星 | 36% | 4% |
| 5星 | 40% | 0 |
| 6星 | 40% | 0 |
| 7星 | 40% | 0 |

1—4星未领取的部分，不作为公司普通利润，而进入导师带教费、培训费、考核认证、技术质量管理等人才培养成本池。

### 2. 指定服务费

客户可以自由选择普通技师、高级技师或专家。

建议：

- 5—6星高级技师：加收约5%—10%指定服务费；
- 7星专家：加收约10%—15%指定服务费；
- 指定服务费100%归被指定技师本人；
- 只有客户主动指定才收取；如果由于排班原因由门店安排高级专家，不额外收费。

指定费首先是一种专业身份认可，其次才是收入。

### 3. 会员与续费经营收益

当前确定的三账模式：

- 会员费：平台40%｜门店30%｜技术侧30%
- 操作费：平台30%｜门店30%｜技术交付池40%
- 升单/续费：平台40%｜门店30%｜技术侧30%
- 指定服务费：100%归指定技师

内部统一记忆：

> 会员433，操作334，续费433，指定费老师100%。

会员和续费的技术侧收益不因师徒关系形成无限层级抽佣。

### 4. 人才复制收入

五星以上获得带教资格后，可以获得：

- 正式培训授课费
- 实操带教费
- 学员认证通过奖
- 培养质量奖
- 技术管理奖

不采用“徒弟以后每做一单，师傅永久抽成”的模式。人才复制收益必须绑定真实培训劳动、考核责任和管理责任。

### 5. 经营与资产收入

员工未来还可以获得：

储备店长奖金 → 店长经营利润奖 → 经营合伙收益 → 门店真实股东收益。

人才收入逐渐从“卖时间”升级为：技术价值 → 专业品牌 → 人才复制 → 经营能力 → 资产收益。

## 六、时间自由也是晋升奖励

星级升级不仅意味着收入提高，也意味着生活品质和职业自主性升级。

### 1—2星：纪律成长阶段

实行固定排班、正常考勤。人多以后采用早晚班轮班。此阶段最重要的是积累案例、练习基本功、观察高级老师、形成稳定服务习惯。

### 3—4星：能力换自由

开始实行弹性排班。在没有预约、培训或团队任务的情况下，可允许前后调整约2小时上下班。

核心不是“少工作”，而是从考勤管理逐步进入结果管理。

### 5—6星：专业自主阶段

原则上采用预约 + 核心服务时段 + 培训任务制，享有更高排班自主权和更稳定的休息安排。

工作评价逐渐从坐班时长转向客户服务量、客户满意度、技术质量、带教质量、课程培训和团队贡献。

### 7星：专家责任制

原则上不要求每天在门店坐班，根据客户预约、专家项目、培训、技术研发和进修学习安排工作。

七星真正的自由来自专业信用：

> 不用用坐班证明价值，要用专业成果证明价值。

七星不是“不用上班”，而是进入专业人士的自我管理阶段。

## 七、人才培养系统

### 第一层：新人入门

目标：建立澜心统一的专业和服务底座。

学习内容包括：澜心价值观、客户隐私、服务边界、基础女性身体知识、基础项目理论、门店服务流程、产品知识、课程体系、卫生安全、沟通规范、客户档案和平台系统。

完成理论考试、实操考核和跟台案例以后进入一星。

### 第二层：1—2星基本功训练

核心目标：标准化。

重点训练操作标准、客户沟通、服务流程、评估基础、产品使用、风险识别和案例复盘。每月至少一次内部技术复训。

### 第三层：3—4星独立能力训练

核心目标：从“会做项目”升级为“会看客户”。

开始训练整体评估、方案组合、项目与课程协同、不同客户差异化处理、长期养护路径、复杂案例判断和客户教育。四星开始培养储备管理能力。

### 第四层：5—6星导师与专家训练

核心目标：从自己优秀升级到能够复制优秀。

增加教学方法、带教、案例督导、技术纠偏、课程表达、团队管理、跨店协作和专家案例讨论。五星必须通过导师资格认证以后才能正式带人。

### 第五层：7星专家进修体系

七星不是终身荣誉，而是动态资格。

七星专家每年必须持续完成：

- 外部进修
- 行业前沿学习
- 内部案例分享
- 导师授课
- 技术复审
- 专业成果输出

公司应为七星专家设置年度学习预算和学习时间，让最优秀的人持续学习，再把新知识带回平台。

## 八、晋升制度

星级不按照工龄自动晋升。

采用：

> 硬门槛 + 数据评分 + 实操考试 + 技术委员会评审

原则上每季度开放一次晋级申请。优秀员工可以主动申请，店长或导师也可以推荐。

建议晋升基本门槛：

- 考核总分≥85分
- 核心实操考核≥90分
- 无重大违规
- 完成当前等级学习任务

具体标准在首店试运行后调整。

## 九、不同阶段考核标准

### 1—4星考核

| 指标 | 建议权重 |
|---|---:|
| 技术能力 | 40% |
| 客户满意与服务体验 | 25% |
| SOP与安全合规 | 20% |
| 学习成长 | 10% |
| 团队协作 | 5% |

低星级员工不把销售额作为最重要晋升指标，避免组织培养出“最会卖卡的人”而不是“最专业的人”。

### 5—7星考核

| 指标 | 建议权重 |
|---|---:|
| 专业技术与复杂案例 | 30% |
| 客户满意、复购、指定 | 20% |
| 带教与人才培养 | 20% |
| 技术标准/课程/研发贡献 | 15% |
| 团队贡献 | 10% |
| 持续学习 | 5% |

安全、重大投诉、违规操作、数据造假、私单等实行红线否决，而不是简单扣分。

## 十、星级不是终身制

1—4星以季度复盘为主；五星以上每年重新认证；七星专家实行年度专家复审。

如果连续两个考核周期明显低于对应星级标准：

辅导期 → 再培训 → 重新考核 → 仍不达标才进行降星。

重大专业安全或诚信问题，可直接暂停相关技术权限。

制度目标不是惩罚，而是保证客户看到“五星、六星、七星”时能够真正信任这个星级。

---

## 十一、储备店长—店长—股东体系

### 储备店长

至少完成一线服务和客户经营训练，进入3—6个月经营训练期，学习人员排班、会员经营、客户投诉、成本、库存、利润表、活动组织、团队沟通、招聘、培训和门店数据。

### 店长

店长是门店CEO，不是“大销售”。

核心考核：经营利润、会员活跃与续费、客户满意、团队稳定、技师成长、成本控制和合规。

店长奖励主要来自经营结果，而不是简单营业额提成。建议达到基本经营目标后，针对超额经营利润设置店长经营奖金池。

### 经营合伙人

连续达到经营要求、能够培养团队、无重大合规问题、真正承担经营责任的人，可以进入经营合伙人阶段。

优先给予门店经营分红权，不急于直接给予工商股权。

### 门店股东

同时满足经营能力、长期价值观、实际责任和投资条件的人，才进入真正门店股权层。

股权必须另行签署正式投资、公司章程、退出、回购和利润分配协议。

---

## 十二、门店复制收益

一个店长或经营合伙人把一家店做成功以后，可以参与复制下一家店。

收益必须来自实际复制工作，而不是发展层级。

### 第一笔：开店复制项目奖金

完成团队搭建、培训、开业和运营系统落地后支付。

### 第二笔：6—12个月经营辅导收益

真正承担新店经营辅导、团队培养和数据复盘，就获得经营辅导收益；辅导结束，项目收益结束。

如果未来持续管理多家店，则正式晋升为区域经营负责人，按照实际管理责任获得区域经营奖金。

不采用“这家店是我发展出来的，所以以后它再开店，我永久层层分钱”的模式。

---

## 十三、人才推荐与人才复制分开

优秀员工可以推荐优秀人才进入澜心。

人才推荐可以设置：入职奖 + 通过试用期奖励，到此结束。

如果五星以上导师真正负责培养这个新人，再按照真实培训劳动领取培训费、带教费和认证奖。

不因“这个人是我招来的”永久获得她未来的业绩分成。

---

## 十四、公司、门店、技师的权责边界

### 公司拥有

品牌、IP、会员制度、定价规则、产品、供应链、课程、技术认证体系、用户系统、数据标准、全国资源和财务结算规则。

### 门店拥有

当地经营自主权、人员调度、客户体验、本地运营和经营利润责任。

### 技师拥有

自己的技术能力、星级身份、客户指定价值、个人专业声誉，以及由专业能力产生的对应收益。

客户可以喜欢、指定某位老师，但会员权益、客户档案和服务记录始终留在澜心系统。

---

## 十五、五种激励同时存在

### 收入升级

星级越高，技术收入、指定收入、培训收入越高。

### 时间升级

固定坐班 → 弹性 → 预约 → 专家自主。

### 身份升级

技师 → 高级技师 → 导师 → 专家 → 首席专家。

### 资源升级

普通客户 → VIP客户 → 全国专家客户 → 平台资源。

### 事业升级

员工 → 店长 → 经营合伙人 → 门店股东。

真正优秀的人获得的不只是简单加薪，而是越来越值钱、越来越自由、越来越有身份、越来越有事业空间。

---

## 十六、系统红线

- 星级不能靠交钱购买。
- 星级不能靠招多少人晋升。
- 导师不能永久抽徒弟业绩。
- 经营负责人不能永久抽自己“发展出来”的下级门店。
- 股东身份不能用虚假的“合伙人”包装普通劳动关系。
- 高级专家的自由必须建立在结果负责和持续专业成长之上。
- 任何激励都不能以牺牲客户利益、技术安全和公司长期利润为代价。

## 十七、V1.0上线方法

第一阶段先用一家门店跑90天。

### 第一个月

完成核心项目SOP、七星技术标准、当前人员暂定星级、基础操作费和技术池测算。

### 第二个月

开始真实执行排班、操作费、客户指定、五星带教和考核记录。

### 第三个月

进行第一次正式晋级评审。

存量员工设置过渡保护期：第一次定级不以降收入为目的，先确定能力位置；以后通过晋级逐渐拉开收入和自由度差距。

90天后重点复盘：

- 技师收入是否提升
- 客户满意度是否提高
- 客户指定率是否出现
- 优秀老师是否愿意带新人
- 低星级员工是否主动学习
- 人员流失率是否下降
- 门店利润是否受到影响

根据真实数据升级为V1.1。

## 十八、组织文化

澜心不是告诉员工：“好好听话，以后公司给你升职。”

而是建立一套清晰的价值交换：

> 你把技术练好，技术会越来越值钱。
>
> 你把客户服务好，客户会愿意为你付指定费。
>
> 你能培养别人，就能突破自己双手的收入上限。
>
> 你能经营团队，就可以成为店长。
>
