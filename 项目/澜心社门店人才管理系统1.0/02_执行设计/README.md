## 执行原则

- 前台简单，后台精细。
- 客户只需理解标准技师/高级技师/专家技师三档。
- 内部保留完整一星—七星成长体系。
- 晋级靠能力、结果与组织贡献，不靠工龄、交钱或发展人员。
- 高星级获得更高收入、更高时间自主权，同时承担更高专业责任。
- 所有制度先在首店进行90天模拟与试运行，再进入V1.1。
